# CSS usage

`@blcklab/moexi-css` turns the canonical Moexi outlines into CSS mask assets. The visible icon uses `currentColor`, so it behaves like text color while keeping SVG-quality geometry.

Use the full stylesheet for convenience, a category stylesheet for a smaller surface, or an individual icon stylesheet when you only need one icon. Multicolor Moexi features stay in the SVG/component packages because a CSS mask has one visible color.
