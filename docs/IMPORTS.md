# Imports

Choose the smallest surface that fits your app.

## Everything

```css
@import '@blcklab/moexi-css';
```

## Regular weight only

```css
@import '@blcklab/moexi-css/regular.css';
```

## One category

```css
@import '@blcklab/moexi-css/categories/development.css';
```

## One icon

```css
@import '@blcklab/moexi-css/icons/search.css';
```

CSS masks are monochrome. Use `@blcklab/moexi` or a framework adapter for multicolor layers and custom icon definitions.
