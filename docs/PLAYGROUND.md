# Playground

The Principia Playground includes editable CSS-only examples for:

- basic icon classes
- thin, regular, and bold weights
- size helpers
- `currentColor`
- buttons and navigation
- status UI
- official aliases
- a cross-section of the icon collection
- accessibility patterns

No package JavaScript runs in these examples.

> Principia inlines CSS assets into its preview. The Playground uses generated `dist/playground.css`, which pins SVG mask URLs to this exact package version on jsDelivr. Normal apps should keep using `@blcklab/moexi-css` or its documented subpath imports.
