# Moexi CSS

Use Moexi icons with CSS classes. No icon font. No runtime JavaScript.

```bash
npm install @blcklab/moexi-css
```

```css
@import '@blcklab/moexi-css';
```

```html
<i class="mx mx-search" aria-hidden="true"></i>
<i class="mx mx-heart mx-bold" aria-hidden="true"></i>
```

The package contains **256 icons**, **3 weights**, category bundles, individual icon stylesheets, and SVG assets.

## Try it

```html playground
<div style="display:flex;gap:16px;font-size:32px">
  <i class="mx mx-search" aria-hidden="true"></i>
  <i class="mx mx-heart mx-bold" aria-hidden="true"></i>
```

Use the full Playground for weights, sizes, colors, aliases, UI patterns, and accessibility.
